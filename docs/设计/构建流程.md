# `cup build`命令

## 第一步：依赖检查(Collect)

以构建项目为基，递归查找其所有依赖项，并检查有效性，以及是否存在循环依赖

有依赖项未找到->构建失败

## 第二步：依赖安装(Install)

安装所有未安装到本地的依赖项

## 第三步：依赖关系建模(Modeling)

读取项目构建所用到的所有依赖项的配置文件，为每个依赖项生成一个唯一标识(名称+标准路径哈希)作为间接索引，构建依赖关系图
同时，对兼容库版本(基于语义化版本号判断)进行依赖项合并

## 第四步：构建脚本生成(Generate)

对依赖关系图中每一项进行构建目标建模，并以构建序(深度优先后序遍历)将构件图转换为线性序列，生成CMake构建脚本

## 第五步：构建(Build)

调用CMake进行构建
